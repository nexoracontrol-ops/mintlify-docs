This quickstart gets you to your first admissible EK-021 decision. You install both parity stacks, run the shared conformance vectors, then build a decision in code against test case TC-001. Every command and code block is grounded in the reference implementations.

## Prerequisites

- Python 3.10 or later (frozen dataclasses and PEP 604 typing)
- Node.js 18 or later
- Both `python/` and `typescript/` folders from the NEXORA Core v1 repository, plus the shared `test-vectors/core-v1.json`

<Steps>
  <Step title="Install dependencies">
    Install the single runtime dep in each stack.

    <CodeGroup>

    ```bash Python
    cd python
    pip install -r requirements.txt
    ```

    ```bash TypeScript
    cd typescript
    npm install
    ```

    </CodeGroup>

    Python installs `rfc8785>=0.1.4`. TypeScript installs `canonicalize@^2.1.0` plus `tsx` and `typescript` as dev dependencies.
  </Step>
  <Step title="Run the shared test vectors">
    Both stacks read `../test-vectors/core-v1.json` and check every case (TC-001-NO-DEVIATION, TC-002-EXCESS-DEDUCTION, TC-003-EVIDENCE_GAP).

    <CodeGroup>

    ```bash Python
    python -m unittest discover -v
    ```

    ```bash TypeScript
    npm test
    ```

    </CodeGroup>

    All three cases must pass in both stacks for the protocol to be considered conformant.
  </Step>
  <Step title="Build a decision in code">
    Construct the TC-001 inputs directly and call `decide()`.

    <CodeGroup>

    ```python Python
    from nexora_core import EK021, EvidenceAnchor, ControlParam
    
    evidence = [
        EvidenceAnchor("A-01", "CUSTODY_AGREEMENT_HASH", "sha256:agreement-001", "registry", "VERIFIED"),
        EvidenceAnchor("A-02", "SIGNED_API_PAYLOAD_AMOUNT", "98000", "bank_api", "VERIFIED"),
    ]
    controls = [
        ControlParam("allowed_fee_pct", "2.0", "CLAUSE-4.1"),
        ControlParam("contract_amount", "100000", "CLAUSE-3.2"),
    ]
    print(EK021(evidence, controls).decide())
    ```

    ```typescript TypeScript
    import { EK021 } from "./nexora_core.js";
    
    const evidence = [
      { anchor_id: "A-01", type: "CUSTODY_AGREEMENT_HASH", value: "sha256:agreement-001", source: "registry", status: "VERIFIED" },
      { anchor_id: "A-02", type: "SIGNED_API_PAYLOAD_AMOUNT", value: "98000", source: "bank_api", status: "VERIFIED" },
    ];
    const controls = [
      { key: "allowed_fee_pct", value: "2.0", source_clause: "CLAUSE-4.1" },
      { key: "contract_amount", value: "100000", source_clause: "CLAUSE-3.2" },
    ];
    console.log(new EK021(evidence, controls).decide());
    ```

    </CodeGroup>
  </Step>
  <Step title="Read the result">
    You get an admissible decision with no deviation.

    ```text Expected result
    status:          ADMISSIBLE_STATE_CONFIRMED
    resolution_type: CONFIRM
    expected_amount: 100000.00
    actual_amount:   98000.00
    delta_amount:    0.00
    reason_codes:    ["FEE_WITHIN_ALLOWED_LIMIT"]
    ```

    The `decision_id` is `EK021-<first 12 hex of input_sha256>`. Both stacks produce the exact same digest, `decision_id`, and monetary strings for this input.
  </Step>
</Steps>
